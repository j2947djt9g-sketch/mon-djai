# Manrope

Manrope is a variable sans-serif by the Manrope Project Authors. These unmodified
WOFF2 files are self-hosted under the SIL Open Font License 1.1; see
`OFL-Manrope.txt`. They cover normal weights 200–800. The interface uses weights
450–700 and system fonts as a fallback, with `font-display: swap`.

Official sources, retrieved 12 November 2026:

- Google Fonts family: https://fonts.google.com/specimen/Manrope
- Project: https://github.com/googlefonts/manrope
- License: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt
- CSS: https://fonts.googleapis.com/css2?family=Manrope:wght@200..800&display=swap
- Latin: https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2
- Latin extended: https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggmxSuXd.woff2

The Latin subset is 24,532 bytes. Latin extended is 15,160 bytes and loads only
for matching characters. French letters and punctuation are included in Latin;
extended Latin supports additional names. No third-party font request is made
by the application.

The licence wording is unchanged; trailing spaces were removed for repository formatting.
