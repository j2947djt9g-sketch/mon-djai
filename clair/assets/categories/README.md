# Illustrations originales des catégories CLAIR

`atlas-v1.webp` : création originale générée pour CLAIR le 11 novembre 2026, sans marque, texte ni personnage protégé. Aucun pack tiers ni attribution externe requis. Le fichier source généré a été réduit en WebP transparent, 768 × 768 px (16 cellules), pour limiter le poids et les requêtes.

Grille 4 × 4, lecture par lignes : panier, repas, bus, maison ; trousse médicale, livres, shopping, loisirs ; tirelire, portefeuille, téléphone, hygiène ; famille, abonnement, imprévus, dossier.

Le mapping est purement visuel dans `accounts/category-art.js` : aucun identifiant ou intitulé financier n’est renommé. Restaurant et santé peuvent illustrer des catégories personnelles existantes ; ils ne créent pas de catégorie. Les pictogrammes vectoriels intégrés prennent le relais si le fichier est indisponible. Les icônes de projets d’épargne choisies par l’utilisateur restent distinctes.
